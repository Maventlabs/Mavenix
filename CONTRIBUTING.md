# Contributing

Thanks for your interest in Mavenix Operator.

This repository is part of the **Mavenix** collection — self-hosted, specialized agentic AI templates. Contributions are welcome for:

- Documentation improvements
- Dockerfile / docker-compose optimizations
- Cross-platform setup fixes (macOS / Windows / Linux)
- SOUL.md template refinements that keep it generic and job-focused
- Bug reports related to this configuration (not OpenClaw itself — report those to the [official repository](https://github.com/openclaw/openclaw/issues))

## How to Contribute

1. Fork this repository
2. Create a new branch: `git checkout -b fix/short-description`
3. Commit your changes: `git commit -m "fix: short description"`
4. Push to your fork: `git push origin fix/short-description`
5. Open a Pull Request

## Before Submitting a PR

- Ensure no credentials or API keys are committed
- Test that `docker build` completes successfully
- Keep `SOUL.md` generic — no personal names, no assumptions about a specific user
- Update `CHANGELOG.md` for any meaningful change

## Code of Conduct

Be respectful and constructive.
